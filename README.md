# 📚 Stories of Unais

> A modern full-stack storytelling platform where administrators can create, edit, manage, and publish stories while users enjoy a clean and responsive reading experience.

---

## 🌟 Overview

Stories of Unais is a secure web application designed for publishing and managing stories. It provides a seamless reading experience for users and a powerful admin panel for content management.

The application is built using React, TypeScript, Node.js, Express, and Supabase, ensuring high performance, scalability, and security.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/makhesh46/storiesofunais.git
```

Move into the project

```bash
cd storiesofunais
```

Install dependencies

```bash
npm install
```

Run Frontend

```bash
npm run dev
```

Run Backend

```bash
cd server
npm install
npm start
```

---

# 🔑 Environment Variables

Create a `.env` file.

VITE_API_BASE_URL=

SUPABASE_URL=

SUPABASE_ANON_KEY=
